# 🔥 FAANG-READY DSA ROADMAP (Complete)

This roadmap is **pattern-driven, interview-focused**, and designed for **FAANG-level preparation**. It emphasizes _thinking, trade-offs, and scalability_ rather than rote memorization.

---

## 🧱 PHASE 0: Programming & CS Foundations (Non‑Negotiable)

### Topics

- Variables, Data Types, Control Flow
- Functions & Recursion
- Stack vs Heap Memory
- Iterative vs Recursive Solutions
- Time & Space Complexity

  - Big-O, Big-Ω, Big-Θ
  - Amortized Analysis

### Interview Expectations

- Explain complexity for every solution
- Justify recursion usage and stack depth

---

## 🟢 PHASE 1: Arrays & Strings (Core Patterns)

### Patterns

1. Traversal / Simulation
2. Two Pointers

   - Same Direction
   - Opposite Direction

3. Sliding Window

   - Fixed Window
   - Variable Window

4. Prefix Sum
5. Binary Search on Sorted Arrays

### Canonical Problems

- Two Sum
- Maximum Subarray (Kadane)
- Longest Substring Without Repeating Characters
- Product of Array Except Self

### Interview Signal

> Can you optimize O(n²) → O(n)?

## 🟢 PHASE 2: Hashing (Optimization Weapon)

- Frequency Map
- Prefix Sum + HashMap

### Problems

- Subarray Sum Equals K
- Longest Consecutive Sequence
- Group Anagrams

### Common Mistake

- Using HashMap where sorting is cheaper

- Dry‑run every solution
- Speak while solving
- Handle edge cases explicitly
